Турнир на выбывание для твоих аудиозаписей ВКонтакте: треки разбиваются на пары, ты выбираешь лучший, при нечётном числе одна группа — тройка; победители проходят в следующий раунд — пока не останется один.

## Запуск

1. Открой свои аудиозаписи: `vk.com/audios<твой id>?section=all`.
2. Нажми F12 → вкладка **Console**.
3. Скопируй весь код из [`vk-king.js`](vk-king.js), вставь в консоль и нажми Enter
   (если браузер не даёт вставить — напечатай `allow pasting` и повтори).
4. Дождись, пока скрипт прокрутит и соберёт все треки, и играй.

## Управление

| Клавиша | Действие |
|---|---|
| ← / ↓ / → | выбрать левый / средний (в тройке) / правый трек |
| 1 / 2 / 3 | слушать трек |
| пробел | пауза |

Музыка играет через родной плеер ВК, есть перемотка. Скрипт работает только в твоём браузере и никуда не отправляет данные.

## Пробный запуск

[`vk-king-test.js`](vk-king-test.js) — тот же скрипт, но турнир только из 10 треков, чтобы быстро дойти до финала.
Свой лимит можно задать и в основном скрипте: перед вставкой выполни `window.KH_LIMIT = 50;` (действует на один запуск).
