Турнир на выбывание для твоих аудиозаписей ВКонтакте: треки разбиваются на пары, ты выбираешь лучший, при нечётном числе одна группа — тройка; победители проходят в следующий раунд — пока не останется один.

## Запуск

1. Открой свои аудиозаписи: `vk.com/audios<твой id>?section=all`.
2. Нажми F12 → вкладка **Console**.
3. Скопируй весь код из [`vk-king.js`](vk-king.js), вставь в консоль и нажми Enter
   (если браузер не даёт вставить — напечатай `allow pasting` и повтори).
4. Дождись, пока скрипт прокрутит и соберёт все треки, и играй.

## Управление

| Клавиша | Действие |
|---|---|
| ← / ↓ / → | выбрать левый / средний (в тройке) / правый трек |
| 1 / 2 / 3 | слушать трек |
| пробел | пауза |

Музыка играет через родной плеер ВК, есть перемотка. Скрипт работает только в твоём браузере и никуда не отправляет данные.

## Турнир не из всех треков, а из части

Скрипт идёт по списку сверху вниз, а сверху в ВК — последние добавленные. Поэтому «часть» — это всегда **N самых свежих** треков.

### Способ 1. Кнопка «Хватит»

1. Запусти скрипт как обычно.
2. Пока идёт сбор, под счётчиком есть кнопка **«Хватит, играть с N треками»** — число на ней растёт.
3. Нажми её, когда наберётся сколько хочешь, — турнир начнётся с уже собранными.

Удобно, если точное число не важно.

### Способ 2. Точное число треков

1. Открой консоль на странице аудиозаписей (F12 → Console).
2. Сначала выполни строку с нужным числом, например:
   ```js
   window.KH_LIMIT = 100;
   ```
3. Сразу после этого вставь код из [`vk-king.js`](vk-king.js) и нажми Enter.

Скрипт соберёт ровно 100 последних треков и начнёт турнир. Лимит действует на один запуск: следующий запуск без этой строки снова возьмёт все треки.

Удобные числа — степени двойки (16, 32, 64, 128, 256, 512): тогда в каждом раунде ровно пары, без троек.

### Способ 3. Пробный турнир на 10 треков

[`vk-king-test.js`](vk-king-test.js) — тот же скрипт с уже прописанным лимитом 10. Вставил — и за 7 выборов дошёл до финала.
